# Proyecto Landing Amazon S3

Landing academica y modular sobre Amazon S3 construida con HTML, CSS y JS vanilla.

## Enfoque
- Presentacion clara para Arquitectura de Software.
- Navegacion principal por tabs.
- Estetica elegante y suave para Maria Fernanda.
- Contenido tecnico resumido para estudiar y sustentar.

## Contenido
- Vision general de Amazon S3
- Uso real y precondiciones
- Arquitectura, patrones y antipatrones
- Costos y decisiones de optimizacion
- Ruta de aprendizaje basico -> avanzado
- Cierre ejecutivo
